# Crypto trading

Crypto runs as **two separate books**, `crypto_demo` and `crypto_real`. They are fully isolated from
the stock books (`demo` / `real`): different currency (USDT/INR), 24×7 hours, their own risk limits,
kill switch and journal. In the app, pick **🪙 Crypto** × **🧪 Demo / 💰 Real**.

## Exchanges

Any of the **104 exchanges supported by [CCXT](https://github.com/ccxt/ccxt)** 4.5.x can be used.
The app lists them under **Profile → Crypto exchanges** with India flags. The API endpoint is
`GET /api/v1/market/crypto-exchanges`, and the list is generated by
`packages/brokers/scripts/gen-crypto-exchanges.mjs`.

| Group                                       | Exchanges (CCXT id)                                                                     |
| ------------------------------------------- | --------------------------------------------------------------------------------------- |
| Reported FIU-IND registered (offshore)      | Binance `binance`, KuCoin `kucoin`, Bybit `bybit`, Coinbase `coinbase`, Bitget `bitget` |
| Indian, in CCXT                             | ZebPay `zebpay`, Mudrex `mudrex`, Bitbns `bitbns` (no candle history), Delta `delta`    |
| Indian, **not** in CCXT (not supported yet) | CoinDCX, WazirX, CoinSwitch, Giottus                                                    |
| Reported to have exited India               | OKX `okx`                                                                               |
| Region-locked                               | `binanceus`, `okxus`, `bybiteu`, `bybitid`, `gateeu`, `coinbaseinternational`           |
| Everything else (≈85)                       | Available technically; India status not verified                                        |

> ⚖️ **India flags are best-effort from public reports.** Always check the current FIU-IND
> registration yourself (fiuindia.gov.in). Crypto is **not SEBI-regulated**. Gains are taxed at
> **30%**, and **1% TDS** is deducted on sells above the threshold.

## What is different from stocks

|               | Stocks                        | Crypto                                                                        |
| ------------- | ----------------------------- | ----------------------------------------------------------------------------- |
| Hours         | NSE session, 15:10 square-off | **24×7**, no square-off                                                       |
| Quantity      | Whole shares or lots          | **Fractional** (exchange step, e.g. 0.00001 BTC) + exchange minimums          |
| Short selling | Intraday / futures            | **Spot = long-only**; shorts only on **PERP** instruments                     |
| Costs         | Brokerage, STT, stamp, GST…   | Taker fee (default 0.1%) + 18% GST on fees; 1% TDS reported separately        |
| Static IP     | Mandatory (SEBI) for orders   | Not required, but **restrict your API key to your server IP** on the exchange |
| Live data     | Broker API                    | **Public exchange data, free, no API key**                                    |

## Demo crypto (free)

```bash
# 1. Instruments: build them from exchange metadata (lot/tick sizes, minimums)
pnpm --filter @atb/backtesting download:crypto -- --exchange binance --symbol BTC/USDT --tf 5m --out data
#    → data/binance_BTC-USDT-5m.instrument.json  (put one or more into instruments.json as a JSON array)

# 2. Gateway (laptop or VM)
MARKET=CRYPTO CRYPTO_EXCHANGE=binance ACTIVE_BROKER=paper \
INSTRUMENTS_FILE=./instruments.json CONTROL_PLANE_URL=https://<worker> GATEWAY_HMAC_SECRET=... \
GATEWAY_NODE_ID=crypto-1 node services/execution-gateway/dist/main.js
```

In the app, switch to **🪙 Crypto → 🧪 Demo**, then go to **Controls → Enable trading**. Stocks and
crypto can run at the same time with **two gateway processes** (one `MARKET=STOCKS`, one
`MARKET=CRYPTO`).

## Real crypto

1. Create an exchange API key with **trade permission only**. Never enable withdrawals, and restrict
   the key to your gateway's IP.
2. Configure the gateway:
   ```bash
   ACTIVE_BROKER=crypto
   CRYPTO_API_KEY=...
   CRYPTO_API_SECRET=...
   # OKX / KuCoin / Bitget also need a passphrase
   CRYPTO_API_PASSWORD=...
   ```
3. Test on the exchange testnet first with `CRYPTO_SANDBOX=true`. Binance, Bybit and OKX support
   testnets.
4. In the app, go to **🪙 Crypto → 💰 Real** and move through **SHADOW → CANARY → LIVE**, exactly as
   with stocks.

Stops are placed on the exchange as stop-limit orders (`triggerPrice`). On exchanges without
`editOrder`, a stop is tightened with cancel + re-place.

## Backtest on real data

```bash
pnpm --filter @atb/backtesting download:crypto -- --exchange kucoin --symbol BTC/USDT --tf 1h --from 2024-01-01
pnpm --filter @atb/backtesting backtest -- --csv data/kucoin_BTC-USDT-1h.csv \
  --instrument data/kucoin_BTC-USDT-1h.instrument.json --tf 1h --capital 10000 --walk-forward
```

**Current result (honest):** on real KuCoin BTC/USDT data the default rule ensemble **FAILS**
walk-forward, both on 5m (Jun–Sep 2026) and on 1h (2024–2026). Fees are roughly equal to the
losses: before costs it is about break-even, and after 0.1% taker + GST it loses. Do not trade
crypto with real money on these settings. Options that may help:

- lower fees (maker orders, VIP tier)
- higher timeframes
- fewer trades (higher `minScore`)
- a validated meta-label model
